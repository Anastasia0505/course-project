РОЗДІЛ 15. Артефакт системи

15.1. Основний артефакт:

Система управління завданнями (To-Do List) є
веб-орієнтованим програмним продуктом.

Тип артефакту: Веб-додаток

15.2. Характеристики артефакту:

1. Платформа:
   - Веб-браузер (Chrome, Firefox, Safari)
   - Доступ з будь-якого пристрою з інтернетом

2. Клієнтська частина:
   - HTML5, CSS3, JavaScript
   - Адаптивний дизайн

3. Серверна частина:
   - Мова: PHP / Python / Node.js (на вибір)
   - Веб-сервер: Apache / Nginx

4. База даних:
   - MySQL
   - Таблиці: users, tasks

15.3. Форми поставки артефакту:

1. Вихідний код:
   - Зберігається у репозиторії GitHub
   - Доступний для перегляду викладачу

2. Документація:
   - 16 розділів у текстових файлах
   - README.md з описом проекту

3. Виконуваний продукт:
   - Працююча веб-система
   - Доступна за URL (локально або на хостингу)

15.4. Відповідність вимогам:

| Вимога                    | Відповідь артефакту        |
|---------------------------|------------------------------|
| Реєстрація користувачів   | Реалізовано               |
| Створення завдань         | Реалізовано               |
| Редагування завдань       | Реалізовано               |
| Видалення завдань         | Реалізовано               |
| Відмітка виконання        | Реалізовано               |
| Фільтрація завдань        | Реалізовано               |
| Адмін-панель              | Реалізовано               |

15.5. Висновок:

Артефакт повністю відповідає поставленим вимогам
та є готовим до демонстрації у рамках курсової роботи.
