РОЗДІЛ 6. Архітектура системи та залежності між підсистемами

6.1. Загальна архітектура системи:

Система побудована за архітектурою клієнт-сервер.

Компоненти:
┌─────────────────────────────────────────────────┐
│                 Клієнтська частина              │
│              (Frontend - веб-браузер)           │
│  - HTML/CSS/JavaScript                          │
│  - React.js / Vue.js (опціонально)              │
└─────────────────────────────────────────────────┘
                        ↓ HTTP/HTTPS
┌─────────────────────────────────────────────────┐
│                 Серверна частина                │
│              (Backend - API сервер)             │
│  - Node.js / Python / PHP                       │
│  - REST API                                     │
│  - Автентифікація (JWT)                         │
└─────────────────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────┐
│                 База даних                      │
│              (MySQL / PostgreSQL)               │
│  - Зберігання користувачів                      │
│  - Зберігання завдань                           │
└─────────────────────────────────────────────────┘

6.2. Підсистеми та залежності:

1. Підсистема автентифікації:
   - Залежить від: База даних (користувачі)
   - Використовується: Всіма іншими підсистемами

2. Підсистема управління завданнями:
   - Залежить від: База даних (завдання), Автентифікація
   - Використовується: Користувацький інтерфейс

3. Підсистема адміністрування:
   - Залежить від: База даних (користувачі, завдання), Автентифікація
   - Використовується: Адмін-панель

4. Підсистема звітування:
   - Залежить від: База даних (статистика)
   - Використовується: Адмін-панель
