РОЗДІЛ 7. Модель даних

7.1. Таблиці бази даних:

Таблиця 1: users (користувачі)
┌─────────────┬──────────────┬─────────────────────────┐
│ Поле        │ Тип          │ Опис                    │
├─────────────┼──────────────┼─────────────────────────┤
│ id          │ INT (PK)     │ Унікальний ідентифікатор│
│ username    │ VARCHAR(50)  │ Ім'я користувача        │
│ email       │ VARCHAR(100) │ Електронна пошта        │
│ password    │ VARCHAR(255) │ Хеш пароля              │
│ role        │ ENUM         │ Роль (user/admin)       │
│ created_at  │ DATETIME     │ Дата реєстрації         │
└─────────────┴──────────────┴─────────────────────────┘

Таблиця 2: tasks (завдання)
┌─────────────┬──────────────┬─────────────────────────┐
│ Поле        │ Тип          │ Опис                    │
├─────────────┼──────────────┼─────────────────────────┤
│ id          │ INT (PK)     │ Унікальний ідентифікатор│
│ user_id     │ INT (FK)     │ Посилання на users.id   │
│ title       │ VARCHAR(200) │ Назва завдання          │
│ description │ TEXT         │ Опис завдання           │
│ status      │ ENUM         │ Статус (new/done/cancel)│
│ deadline    │ DATETIME     │ Дедлайн виконання       │
│ created_at  │ DATETIME     │ Дата створення          │
│ updated_at  │ DATETIME     │ Дата останньої зміни    │
└─────────────┴──────────────┴─────────────────────────┘

7.2. Зв'язки між таблицями:

users (1) ────── (N) tasks
Один користувач може мати багато завдань

7.3. ER-діаграма (текстове представлення):

┌──────────────┐       ┌──────────────┐
│    users     │       │    tasks     │
├──────────────┤       ├──────────────┤
│ id (PK)      │──1────│ user_id (FK) │
│ username     │    N  │ id (PK)      │
│ email        │       │ title        │
│ password     │       │ description  │
│ role         │       │ status       │
│ created_at   │       │ deadline     │
└──────────────┘       └──────────────┘
